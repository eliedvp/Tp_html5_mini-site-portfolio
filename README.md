# Mini-site portfolio — HTML5

Exercice réalisé pendant la formation GoMyCode : construire un petit site portfolio de plusieurs pages reliées entre elles, en HTML5.

## Pages

Tous les fichiers sont dans le dossier `portfolio/` :

- `index.html` : accueil, photo, menu vers les autres pages et lien vers un CV ;
- `about.html` : compétences et parcours ;
- `projects.html` : trois projets présentés avec une image ou une vidéo (`<video>`) ;
- `contact.html` : formulaire de contact (champs obligatoires avec `required`).

Chaque page secondaire propose un lien « RETOUR » vers l'accueil.

## Notions travaillées

- Site multipage et liens relatifs entre pages
- Images et vidéos (`<img>`, `<video>`)
- Formulaires HTML5 (`input`, `textarea`, validation `required`)
- Listes et titres

## Stack

HTML5. Le fichier `portfolio/css/style.css` est présent mais vide : le site n'a pas encore de mise en forme.

## Lancer le projet

Ouvrir `portfolio/index.html` dans un navigateur.
